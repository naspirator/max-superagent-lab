### Дополнительно исправлено после цикла 3 (без новой приёмки)

При фактической проверке кода обнаружено, что часть заявленных исправлений
была неполной:

1. `active/<uid>` писало только меню, а прямая запись режима — нет. Теперь
   маркер пишет `ModeStore.set_setting`; `is_test` при ошибке SQLite
   возвращает fail-closed `True`.
2. Числовой `item_id` (`token_hex(6)` иногда только из цифр) трактовался как
   индекс. Теперь сначала ищется `item_id`, затем индекс с проверкой границ.
3. `staff:<id>` перехватывался веткой списка. Теперь карточка сотрудника
   доступна.
4. Новый ID сотрудника считался по активным и падал на `UNIQUE` после
   деактивации максимального. Теперь ID считается по всем записям.
5. Ансамбль не заменяет строку с отрицательным слагаемым, даже если знак
   записан внутри `terms`.

Добавлены 5 регрессионных тестов `tests/test_cycle3_regressions.py`.
Эти изменения **не проходили** независимую проверку ChatGPT — вердикта по ним
нет.

## Не готово / блокеры

1. **APPROVE ChatGPT не получен.** Проведено три цикла; последний вердикт —
   REVISE. Лимит трёх циклов исчерпан. Четвёртый цикл не проводился;
   пост-цикловые исправления не проверены независимо. Без APPROVE внедрение и
   отправка владельцу на согласование не выполнялись.
2. **Superagent-ревью не получено.** Сервис запущен, PR #38 и Issue #39
   созданы. Причина техническая: GitHub-источник Superagent пропускает
   элементы, автор которых совпадает с логином агента
   (`src/sources/github.ts:227`, `if sameName(item.user.login, login) continue`;
   также `author()` ставит `human=false` для self-authored). Единственный
   доступный аккаунт — `max535max`, он же агент. Самостоятельно создать
   «человеческий» триггер невозможно; второго аккаунта/токена нет.
3. **Точность OCR недостаточна для автоматической сдачи:** последний прогон —
   суммы 82,8% (старый 86,2%), сотрудники 42,1%, категории 75,9%, полностью
   верных 0/5. Диапазон по прогонам: суммы 82,8–89,7%, сотрудники 42,1–52,6%,
   категории 75,9–82,8%. Нужна ручная проверка каждой позиции.
4. Живой Telegram не тестировался: второй polling на действующем токене
   запрещён до согласования.
